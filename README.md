## About this entry

One original dad joke, delivered in a single line: a deadpan bit of
bad news for a suitcase that lands on emotional baggage — and a case
that still refuses to unpack. No setup beyond the line itself, just
the pun, the groan, and a completely straight face.

The joke lives as a constant in `main.ts`. Running the program checks
that the line is within the 200-character limit and writes it, as
UTF-8 text, to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

By default the output goes to `/output/entry.txt`. Set `OUTPUT_DIR`
to write somewhere else:

```sh
OUTPUT_DIR=/tmp/test-out-dadjoke node main.ts
```
